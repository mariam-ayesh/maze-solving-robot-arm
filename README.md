# Maze-Solving Robotic Arm

A fully automated Python/OpenCV pipeline that detects a maze with a vision system, solves it, and drives a Dobot Magician Lite arm to physically trace the solution. I used Claude to verify the coordinate transformation between the vision system and the robot's physical workspace.

Solo graduate project, Arizona State University, Fall 2025.

**Tools:** Python, OpenCV, NumPy, Dobot Magician Lite
